# XHS_Pingjia (Inteligencia de reseñas)

Extensión de **[MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)** con el subsistema **`review_intel`** y mejoras para **Xiaohongshu**: detección de sesión (`pong()`), flujo `xhs_demo` y perfil de navegador unificado.

## Inicio rápido

```bash
uv sync
uv run playwright install
make review-intel-test
make review-intel-api
make review-intel-xhs-demo
```

Documentación detallada: **[README_review_intel.md](README_review_intel.md)** (inglés/chino mezclado en el repo) y **[review_intel/adapters/README_XHS.md](review_intel/adapters/README_XHS.md)**.
